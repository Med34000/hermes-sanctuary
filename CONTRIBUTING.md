# Contribuer · Contributing

*2026-11-04 ≈18:55 (Europe/Zurich) — Claude (Cowork) — Anthropic, Claude Opus 5.5, pour Médéric Morin*

## 🇫🇷
Merci de passer par ici ! Ce projet est partagé **justement pour recevoir des avis et des idées**.

- **Une idée, un avis, une question ?** Ouvre une *issue* « Idée » (ou une discussion si elles sont activées). Une phrase suffit, même une critique.
- **Un bug ?** Utilise une *issue* « Bug », en indiquant ta version de Hermes, ce que tu as fait, ce que tu as vu, et une capture si possible. **Ne colle jamais de clé API ni ton `.env`.**
- **Du code ?** Ouvre d'abord une issue pour en parler, puis une *pull request* courte, centrée sur un seul sujet.
- **Ce qui m'aiderait le plus** :
  - de nouveaux environnements et personnages ;
  - une meilleure correspondance entre outils et compagnons ;
  - l'affichage sur téléphone ;
  - la sécurité ;
  - l'installation sous Docker ;
  - la prise en charge d'autres agents ;
  - des traductions.

Règles du projet : aucun contenu de conversation dans l'état, tout en local par défaut, une instance Hermes par personne.

**Licence des contributions** : en proposant une contribution, tu acceptes qu'elle soit publiée sous les licences du dépôt ([LICENSE](LICENSE), [LICENSE-ASSETS](LICENSE-ASSETS)), et que Médéric Morin puisse aussi l'utiliser, la modifier et la proposer sous d'autres conditions, y compris commerciales. C'est ce qui lui permet de continuer à faire vivre le projet. Ton nom sera crédité.

## 🇬🇧
Thanks for stopping by! This project is shared **to get feedback and ideas**.

- **Idea, opinion, question?** Open an "Idea" issue (or a discussion if enabled). One sentence is enough, criticism included.
- **Bug?** Open a "Bug" issue with your Hermes version, what you did and what you saw. **Never paste API keys or your `.env`.**
- **Code?** Open an issue first, then a small, focused pull request.
- **Most wanted**:
  - new environments and characters;
  - better tool mappings;
  - mobile layout;
  - security;
  - Docker install;
  - support for other agents;
  - translations.
